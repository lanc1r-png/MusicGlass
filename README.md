# Opal (MusicGlass)

Музыкальный плеер для iPhone в стиле Apple Music с дизайном Liquid Glass (iOS 26+).

## Что умеет
- **Медиатека.** Играет музыку прямо из папки «Файлы» → «На iPhone» → «Opal» → «Музыка», без копирования. Есть альбомы, исполнители, песни с алфавитной полоской, избранное и свои категории с перетаскиванием.
- **Плеер.** Живой фон под цвет обложки, светлая и тёмная тема, бесшовный переход или плавное затухание между треками, AirPlay, управление с экрана блокировки.
- **Онлайн.** Поиск и прослушивание треков из открытого каталога Audius, своё избранное и плейлисты.
- **Радио.** Тысячи интернет-станций из каталога radio-browser.info, жанры, страны, «Мои станции», название песни из эфира.
- **Теги.** Поиск названий и обложек в iTunes и MusicBrainz и запись их в MP3.

## Сборка
Проект собирается в GitHub Actions (`.github/workflows/build.yml`): XcodeGen создаёт проект из `project.yml`, xcodebuild собирает неподписанный `MusicGlass.ipa`. Его можно скачать в артефактах запуска и подписать своим сертификатом.

## Структура
- `Player.swift`: воспроизведение, очередь, переходы между треками, экран блокировки.
- `Library.swift`: сканирование папки, теги, кэш обложек.
- `LibraryHome.swift`, `LibraryLayout.swift`: главный экран медиатеки, категории, профиль.
- `NowPlayingScreen.swift`, `MiniPlayer.swift`: экран «Сейчас играет» и мини-плеер.
- `Audius.swift`, `OnlineView.swift`, `OnlineLibrary.swift`: онлайн-вкладка.
- `Radio.swift`, `RadioView.swift`: радио.
